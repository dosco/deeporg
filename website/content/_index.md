<section id="engine" class="dx-value"><div class="dx-value-copy"><p class="dx-kicker"><b>How it works</b></p><h2>The agent writes a query. Your database runs it.</h2><p>Most company agents need someone to write a tool for every kind of question. DeepORG reads your systems and builds a map of them instead. The agent uses the map to write a query. DeepORG checks that query against your access rules and compiles it into a single database query, so the joins, sums and rankings happen in your database, not in the model.</p><div class="dx-contrast" role="table" aria-label="A typical company agent compared with DeepORG"><div role="row"><span role="columnheader"><span class="sr-only">What changes</span></span><span role="columnheader">A typical agent</span><span role="columnheader">DeepORG</span></div><div role="row"><b role="rowheader">Setting it up</b><span role="cell">A tool written by hand for each question</span><span role="cell">A map read from your schemas and APIs</span></div><div role="row"><b role="rowheader">A new system</b><span role="cell">Another set of tools to write</span><span role="cell">A few lines of config</span></div><div role="row"><b role="rowheader">Totals and rankings</b><span role="cell">The model adds up the rows it was handed</span><span role="cell">Your database computes them</span></div><div role="row"><b role="rowheader">Access rules</b><span role="cell">Coded into each tool</span><span role="cell">Checked on every query</span></div></div><p>The engine is open source under Apache 2.0, and you can use it without the agent, as an API server or a Go library.</p><div class="dx-links"><a class="dx-more" href="/why/no-hand-built-tools/">Why no hand-built tools</a><a href="/why/open-engine/">The engine on its own</a><a href="/core/compiler/">Compiler docs</a></div></div><div class="dx-value-art">{{< ascii scene="how" label="Animated diagram of one question in seven steps: ask, find the tables in the map, write a query, check it against your access rules, compile it to one SQL statement, run it in your database, and answer with what was run." caption="from a question to one database query" >}}</div></section>

<section id="reasons" class="dx-pillars" aria-labelledby="reasons-title"><div class="dx-pillars-head"><div><p class="dx-kicker"><b>Safety</b></p><h2 id="reasons-title">Why you can trust it with real data.</h2></div><p>Three things keep it safe. Each has its own page that says how it works and where its limits are.</p></div><div class="dx-pillar-grid"><a id="evidence" class="dx-pillar" href="/why/answers-with-evidence/"><span>01</span><h3>A made-up answer is blocked.</h3><p>Every name and number in an answer has to come from a query the agent actually ran. An answer that claims something with nothing behind it is blocked.</p><em>Answers with the data behind them</em></a><a id="rules" class="dx-pillar" href="/why/your-rules/"><span>02</span><h3>It sees only what you allow, and asks before it changes anything.</h3><p>Your rules about who may see which rows and columns apply to every query the agent writes. A change is tried out first, shown to you, and held until you approve it.</p><em>Your rules, your approval</em></a><a id="terms" class="dx-pillar" href="/rollout/#terms"><span>03</span><h3>You can teach it your terms, and correct it when it is wrong.</h3><p>Write down once what “active customer” means. After someone approves the note, the agent reads it whenever it uses that table. When someone marks an answer wrong, DeepORG keeps the correction with the queries behind the answer.</p><em>Your terms, your corrections</em></a></div></section>

<section id="problem" class="dx-pillars dx-problem" aria-labelledby="problem-title"><div class="dx-pillars-head"><div><p class="dx-kicker"><b>Why AI rollouts stall</b></p><h2 id="problem-title">Company data has no test suite.</h2></div><div><p>Coding agents took off because a test tells you in minutes whether the work is right. Company data has no such check. It sits in a dozen systems, under rules about who may see what, and a confident wrong answer looks just like a right one. So most rollouts need a team of consultants to connect the systems and check the answers. DeepORG does that work for you.</p><div class="dx-links"><a class="dx-more" href="/rollout/">What a rollout takes, step by step</a></div></div></div></section>
